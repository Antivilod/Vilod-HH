Проверочная серия

До пяти полных карточек за запуск. Ссылки добавляются кнопкой расширения из открытой выдачи HH. Прямой импорт Excel здесь пока не подключён. Карточки останутся в Chrome для проверки.

Запуск разрешает чтение очереди. После серии или остановки очередь снова ставится на паузу. Сохранённые карточки останутся в базе. Для передачи помощнику выгрузите очередь на анализ из рабочей панели.

Диагностика доступа
Проверяется только публичный поиск API из Chrome. Авторизация и отправка этим не проверяются.


Защита Windows и VPN не изменяются. Проверки сайта не обходятся.
