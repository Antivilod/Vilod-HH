# Vilod HH

Расширение Google Chrome для работы с вакансиями HeadHunter. Помогает сохранять вакансии, собирать информацию о работодателях и передавать материалы внешнему ИИ-помощнику для анализа и подготовки индивидуальных сопроводительных писем.

Версия: **0.13.14**. Публичная версия поставляется с пустым профилем, без личных данных и истории откликов. Собственный код можно использовать и адаптировать под свои задачи по лицензии MIT.

## Возможности

- Сохранение открытой карточки вакансии и описания работодателя.
- Поиск по направлению, свежести и удаленному формату.
- Локальный профиль, история, резервные копии и проверка возможных повторов.
- Экспорт отдельных вакансий и пакетов JSON, импорт результатов внешнего анализа.
- Сохранение вопросов анкеты, материалов формы и проверяемых черновиков.
- Дополнительный обмен через выбранную пользователем локальную папку.

Расширение самостоятельно не подключается к ChatGPT, не содержит языковой модели и не отправляет отклики. Анализ и индивидуальные письма должен подготовить внешний помощник или пользователь. Заполнение не является подтверждением отправки. История расширения не заменяет полную историю аккаунта HH.

## Установка

1. Скачайте репозиторий и распакуйте его в постоянную папку.
2. Откройте `chrome://extensions`, включите режим разработчика.
3. Нажмите «Загрузить распакованное расширение» и выберите папку `extension`.
4. Откройте Vilod HH через меню расширений, затем рабочую панель.
5. В «Мой профиль» заполните собственные данные и направления. По умолчанию профиль пустой.
6. Войдите в HH самостоятельно, откройте полное описание вакансии и сохраните его кнопкой расширения.

Это не опубликованная сборка Chrome Web Store. Обычный способ установки - загрузка распакованной папки. После правок исходников можно перезагрузить расширение на странице расширений.

## Обмен с помощником

Простой вариант - экспорт и импорт JSON через интерфейс. Для папочного обмена скопируйте `exchange-template/Обмен HH` в отдельное место вне репозитория и выберите эту папку в панели. Файл-маркер обозначает публичный формат, а не чей-либо личный чат. Материалы сохраняются в «На анализ», ответы читаются из «Результаты». Сторонний помощник должен отдельно получить доступ к этой папке. Само подключение папки не запускает помощника.

Экспорт содержит профиль, тексты вакансий и другие сохраненные данные. Не публикуйте заполненные JSON, снимки форм и резервные копии. Подробности: [PRIVACY.md](PRIVACY.md).

## Адаптация

- `extension/profile.mjs` - пустая структура профиля и проверка полей.
- `extension/triage.mjs` - консервативные правила предварительной оценки.
- `extension/extract.mjs`, `company-reader.mjs`, `questions.mjs` - чтение страниц.
- `extension/exchange.mjs`, `batch.mjs`, `folder-exchange.mjs` - протокол обмена.
- `extension/dashboard.html`, `dashboard.mjs`, `styles.css` - интерфейс.
- `extension/worker.mjs`, `local-store.mjs` - фоновые команды и локальное состояние.

Часть логики предварительного отбора ориентирована на QA и работу из России. Для других профессий и стран адаптируйте правила, подписи и поля, а не только название направления. Верстка HH может измениться; извлечение нужно проверять на реальных страницах. Проверка API в дополнительных инструментах не подтверждает OAuth или право отправлять отклики.

## Разрешения и ограничения

`activeTab`, `scripting`, `storage` используются для чтения выбранных страниц и локального хранения. Дополнительные разрешения ограничены доменами HH. Снимок формы может содержать персональные данные. Расширение не меняет VPN, не обходит CAPTCHA, сертификаты или защиту Windows. Пользователь отвечает за соблюдение правил площадки.

## Проверка публичной копии

Node.js 20+: `node tools/check-public.mjs`.

Проверка контролирует пустое начальное состояние, отсутствие встроенной истории, локальные импорты, файлы манифеста и контрольные суммы файлов расширения. Это не заменяет живую проверку интерфейса Chrome. После изменения файлов расширения обновите контрольные суммы: `node tools/rebuild-release.mjs`.

Сторонние фрагменты и лицензии перечислены в `extension/THIRD_PARTY_NOTICES.txt`. Общая лицензия проекта: MIT.

## Сборка и зависимости

Отдельный сборщик и установка npm-пакетов не требуются: папка `extension` содержит исходные HTML/CSS/JS-модули и ресурсы для загрузки как распакованного расширения. Node.js нужен для инструментов проверки, а не для обычной работы расширения в Chrome. Сторонние адаптированные фрагменты перечислены в `extension/THIRD_PARTY_NOTICES.txt`; их MIT-лицензии сохранены полностью. Внешняя модель и API-ключи для установки не нужны.
