# Проверка публичного снимка Vilod HH 0.13.14

Дата: 2026-11-02. Этот отчёт описывает локальную проверку перед веб-публикацией в отдельный репозиторий. Факт публикации, публичные коммиты и тег проверяются отдельно после загрузки.

## Область

Получен доступ только к предоставленной подготовленной папке. В ней 66 файлов и нет .git, поэтому прежняя история, ветки, теги, авторы и удалённые объекты отсутствуют в предоставленном наборе. Публичная история начинается заново от аккаунта владельца через сайт GitHub. Не использовались рабочее браузерное хранилище HH, личные экспорты, резервные копии, резюме или другие локальные проекты.

Для публикации создана отдельная копия. Исходная папка сохранена без изменений. Все 54 файла extension и оба исходных инструмента tools сохранены побайтово, включая версию 0.13.14 и исходный release-ready.json. Подготовительный отчёт перенесён в audit/PREPARATION-REPORT.txt без изменения содержимого. README дополнен описанием назначения, установки, настройки, сборки, проверок и ограничений. Добавлены правила сохранения байтов в Git и дополнительные исключения локальных настроек и сертификатов. Собственная документация использует короткие дефисы.

## Проверки файлов и метаданных

Все 53 SHA-256 в исходном extension/release-ready.json совпали с файлами; набор файлов полностью соответствует этому манифесту вместе с самим release-ready.json. Проверен JSON. Для всей публикации добавлен INVENTORY.json с размерами и SHA-256 каждого файла, кроме самого манифеста.

Все файлы и имена проверены эвристически: домашние пути, имя локального профиля ОС, контакты, полные SID, приватные ключи, распространённые токены, credential URL, secret/password/api-key и webhook/JWT. Находок не получено. Запрещённых исполняемых файлов, архивов, пользовательских данных, ключей, сертификатов, логов, неожиданных бинарников, символических ссылок или перенаправлений каталогов в исходной поставке не найдено. Альтернативных потоков NTFS нет.

Проверены пять PNG: присутствуют только IHDR, pHYs, IDAT и IEND; текстовые и EXIF-чанки отсутствуют. pHYs содержит разрешение изображения. Остальные файлы являются текстом или пустыми .gitkeep.

## Выполненные проверки

Node.js 24.19.0. Успешно выполнен предоставленный tools/check-public.mjs: пустые профиль и состояние, отсутствие встроенной истории и загрузчика, маркер выбранной папки, локальные импорты, ресурсы манифеста и контрольные суммы 54 файлов расширения. Через node --check проверены все 42 файла JS/MJS.

Фикстуры шести функциональных проверок из первоначального отчёта в поставке отсутствуют. Их повторный запуск не заявляется. Эта публичная копия не устанавливалась в живой Chrome и не подключалась к аккаунту HeadHunter. Отклики не отправлялись, реальные формы не заполнялись, разрешения браузера не менялись.

## Возможности, сеть и разрешения

Назначение и возможности README сверены с исходниками: вакансии и материалы компаний, профиль, локальная история и резервные копии, JSON-обмен, папочный обмен, вопросы анкет и подготовленные ответы. Расширение не содержит внешней модели, не запускает ChatGPT и не отправляет отклики автоматически. Подготовка полей не считается отправкой. Итоговый анализ и письма требуют внешнего помощника или работы пользователя.

Manifest V3, обычные разрешения activeTab/scripting/storage; дополнительные host permissions ограничены hh.ru, его поддоменами и api.hh.ru. Внешние сетевые обращения в коде относятся к HH; диагностический GET публичного API не передаёт credentials. Проверка self-update читает собственные ресурсы расширения через runtime.getURL, а не загружает внешний исполняемый код. Удалённых JS-библиотек и npm-зависимостей в поставке нет.

Часть логики ориентирована на QA и работу из России. Изменение профессии или региона требует адаптации правил. Вёрстка HH может измениться. Профиль, снимки форм, резервные копии и экспорты, созданные после установки, могут содержать личные данные; их нельзя добавлять в публичный репозиторий.
